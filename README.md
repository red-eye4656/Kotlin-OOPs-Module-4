# Module 4 Assignment: OOPs in Kotlin

## 📌 Overview

This repository contains the solutions for **Module 4: OOPs in Kotlin**.

The assignment demonstrates the fundamental Object-Oriented Programming concepts in Kotlin, including:

- Classes and Objects
- Encapsulation
- Inheritance
- Interfaces
- Polymorphism
- Data Classes
- Functions
- Access Modifiers
- Validation
